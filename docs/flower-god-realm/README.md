# 花神启境 · 十二花神数字艺术展演（交付工程包 V1.1）

## 1. 目录结构

```text
FlowerGodRealm/
├── index.html              # 主展演入口（可直接双击打开）
├── start_preview.bat       # Windows 一键本地服务预览（推荐客户验收使用）
├── start_kiosk.bat         # Windows 展厅大屏全屏模式（隐藏控制条、自动发声、隐藏鼠标）
├── README.md               # 本说明文档
├── videos/                 # 【独立视频目录】放入 01.mp4 ~ 12.mp4，客户替换同名文件即可
│   └── PUT_VIDEOS_HERE.txt
├── css/
│   └── stage.css           # 展演界面、动效与排版样式
├── js/
│   ├── flowers_data.js     # 十二花神配置（诗句、赠语、配色、停留时长）
│   ├── utils.js            # 宣纸纹理、手绘笔触与工笔花卉原语
│   ├── botanical.js        # 底层水墨远山与十二花折枝唤醒动画
│   ├── transitions.js      # 6 套四季差异化切花转场与粒子物理系统
│   ├── audio.js            # 四季雅乐合成引擎
│   ├── fallback_film.js    # 缺视频时的十二景工笔水墨绘卷兜底
│   └── app.js              # 展演状态机与热键控制
└── tools/
    └── local_server.ps1    # Windows 零依赖本地静态服务器（支持视频 Range 流式播放）
```

## 2. 交付前打包步骤（交接方操作）

1. 将您准备好的 12 个视频文件复制到 `videos/` 文件夹中，命名为 `01.mp4` 至 `12.mp4`（或 `01.webm` 至 `12.webm`）。
2. 双击 `start_preview.bat`，在浏览器中依次点击 `01` ~ `12` 验证视频播放与签文尾帧过渡是否正常。
3. 验证无误后，将整个 `FlowerGodRealm` 文件夹压缩打包交付客户即可。

## 3. 客户替换视频方法

客户收到交付包后，**无需修改任何代码**：
1. 打开 `videos/` 文件夹；
2. 用新的视频文件**覆盖同名文件**（例如替换牡丹视频则覆盖 `videos/04.mp4`）；
3. 若展演页面正在运行，按 `F5` 刷新即可加载最新视频。

## 4. 启动方式说明

* **方式 A（推荐，Windows 预览验收）**：双击 `start_preview.bat`。脚本会自动用系统内置 PowerShell 启动本地服务（无需安装 Python/Node.js），自动打开浏览器并支持签文页视频尾帧虚化截帧与防缓存加载。
* **方式 B（展厅大屏无人值守）**：双击 `start_kiosk.bat`。自动以 Chrome / Edge 无边框全屏 Kiosk 模式启动，自动隐藏底部控制条与空闲鼠标，并解除浏览器首次点击才能发声的限制（按 `Alt+F4` 退出全屏）。
* **方式 C（最简免脚本打开）**：直接双击 `index.html` 也可直接读取 `videos/` 中的视频进行预览。

## 5. 常用快捷键

| 按键 | 功能 |
| :--- | :--- |
| `Space` 或待机点击画面 | 随机抽取一签 |
| `1` ~ `9`、`0`、`-`、`=` | 快捷切换 `01` ~ `12` 号花神 |
| `H` | 显示 / 隐藏底部控制条 |
| `F` 或双击空白画面 | 切换全屏 |
| `C` | 切换视频画面比例（等比完整 / 铺满全屏） |
| `M` | 声音开关 |
| `R` | 归境复位至待机态 |
