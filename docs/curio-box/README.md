# 微缩博物箱 (Curio Box) - Step 2 随机拓扑地图引擎

## 启动方式
直接双击 `index.html` 即可在浏览器中运行，免本地服务器。

## 本阶段核心落地
- **正式主角定型**：默认启用 **A · 护目镜冒险团**，同时在 `src/render/drawPlayer.js` 完整保留 B（青花釉面）与 C（嫩芽软绒）两套皮肤供后续局外解锁。
- **随机拓扑引擎 (`src/world/mapGen.js`)**：
  1. 6×6 画布不规则骨架生长（11~13 格），告别死板 3×3。
  2. 多格合并：自动生成 `2×2` 橡皮擦大中庭与 `2×1`/`1×2` 书脊弹射长廊。
  3. 战术造环：生成树 + 2~3 条环路捷径，杜绝撤离死胡同。
  4. BFS 距离梯度与硬约束校验：自动将「高危大金保险库」与「怀表撤离点」分配在远离出生点的不同战略分支上。
  5. 边去重烘焙：3/4 木盒隔板墙 + 铜钉角柱 + 门洞净空保护。
- **验证快捷键**：
  - `R`：一键重随整张地图（顶部实时显示种子、环路数、BFS 步数与生成耗时）
  - `M`：平滑缩放至全图鸟瞰总览（配合 `R` 可连续检视几十张随机地图结构）
  - `F`：开关手绘羊皮纸战争迷雾
