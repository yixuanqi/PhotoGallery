## 本次针对性深度重构（彻底告别同质化与直线平推）
### 1. 四大关卡视觉与材质彻底分家
- **第 1 关 · 晨露荷塘**：明快晴空蓝 + 白云 + 粗糙砂岩苔石地砖（高摩擦）与晶亮天蓝冰镜滑道（极低摩擦）形成鲜明质感反差。
- **第 2 关 · 星象天文台**：**深蓝午夜星空 + 闪烁繁星 + 旋转黄金星座连线 + 柔紫银河星云**；室内切换为深靛蓝大理石星盘地砖、深蓝鎏金天文台石墙与金色星灯。
- **第 3 关 · 暮光古藤廊**：翡翠森雾暮空 + 飘飞暖金萤火虫；深青苔石板、厚苔古藤石墙与暖琥珀灯笼。
- **第 4 关 · 落日鎏金穹**：宫崎骏风粉金晚霞云海 + 镶金边流云 + 皇家象牙暖玉鎏金地砖。

### 18. 帧率 / GC 深度调优、自动化防回归验证与终版封包（v9.3）
- **渲染管线与内存 GC 优化**：
  - **视口裁切（Viewport Frustum Culling）**：`renderer.js` 基于当前镜头视野盒自动剔除屏外浮岛悬崖、地砖、贴地装饰、墙体、道具、守卫与脚印，中低端手机及大地图缩放流畅度显著提升。
  - **零闭包对象池 Y 轴排序**：废弃每帧分配 250+ 匿名闭包对象的 `drawList`，改用复用槽位数组 `drawQueue` + 就地插入排序（近 $O(N)$），消除 60–144Hz 下的新生代 GC 抖动。
  - **云海迷雾与虫洞连脉缓存**：缓存静态云团基底（仅在房间揭雾拓扑变化时重建）与虫洞配对数组 `map._wormholePairs`；缓存小地图边界 `map._miniBounds` 并节流至 ~18Hz 重绘。
  - **瞬态特效池硬上限**：为粒子（160）、脚印（64）、飘字（24）、闪电弧（24）与声波涟漪（18）设置上限并复用库仑力缓冲数组，剧烈跨学科连锁爆发时帧时间依然平稳；同步优化玩家步行越过虫洞环的丝滑碰撞。

  - `tools/verify_release.py`：零依赖 Python 校验脚本，自动执行全模块词法/IIFE/零 ESM 检查、`CB.*` 符号依赖核验、DOM ID 全匹配、数据注册表引用一致性（奇物/守卫/气候 ID）、TapTap 合规与去剧透审计、GC 规范检查及 Bundle 一致性验证（可通过 `python tools/build_release.py --verify` 一键打包并验收）。
