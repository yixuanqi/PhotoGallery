# 月潮孤舟 · Moon Tide Skiff

V13 完整项目工程。游戏现在包含「月潮之海」与「霜穹冰海」两片可探索海域，支持跨海切航，并提供船体强化、遗物与生态图鉴、潜艇涂装和博物委托等内容。

- 在线体验：https://yixuanqi.github.io/PhotoGallery/moon-tide-boat/
- 操作：支持键盘、鼠标和触屏；具体操作以游戏内提示为准。
- 部署：静态网页工程，可直接由 GitHub Pages 或其他静态 Web 服务器托管，无需构建步骤。
- 工程结构：HTML 入口、CSS 样式、模块化 JavaScript、关卡数据及 tools 下的 QA 辅助页面与脚本。
