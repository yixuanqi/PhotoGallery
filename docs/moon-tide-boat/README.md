# 月潮孤舟 · Moon Tide Skiff

Phase 2 网页游戏原型。在 360° 环形月海自由航行，收集碎片升级船体，点亮四座古迹并唤醒潮汐光柱。

- 在线入口：https://yixuanqi.github.io/PhotoGallery/moon-tide-boat/
- 键鼠：A/D 航行并自动掠拾碎片；点按/空格抛钩拉动机关与摆荡；E/右键释放声波共鸣；迎浪峰 W/Shift 完美跃浪。
- 触屏：使用页面内划桨、声波、抛钩和推进按钮。
- 每收集 3 份同类碎片自动完成装船升级。
- 运行：静态 Web 服务器托管，无构建步骤；Canvas 2D / JavaScript / Web Audio。
- 本次保留 Phase 2 ZIP 全部 8 个游戏文件原样。压缩包、JS 语法、Git Blob SHA 已验证；本地浏览器导航受环境限制，实际游玩及真机兼容性尚未验证。
