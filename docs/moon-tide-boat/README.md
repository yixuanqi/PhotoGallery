# 月潮孤舟 · Moon Tide Skiff

V1 网页游戏原型。月亮越来越近，驾驶小船在海中打捞残骸与挂件。

- 在线入口：https://yixuanqi.github.io/PhotoGallery/moon-tide-boat/
- 键鼠：A/D 划桨，点击海面或空格抛钩，获得推进器后 W/Shift 推进。
- 触屏：使用页面内划桨、打捞及推进按钮。
- 运行：直接使用静态 Web 服务器托管项目目录，无构建步骤；Canvas 2D / JavaScript / Web Audio。
- 本次保留上传 ZIP 的全部 8 个游戏文件原样；V1 为原型，完整通关与真机兼容性尚未验证。
