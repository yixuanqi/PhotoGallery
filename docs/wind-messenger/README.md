# 拾风信使 · Wind Messenger

一款单文件 Canvas 2D 手绘横版探索游戏。玩家在阳光山谷中奔跑、跳跃与滑翔，通过划风和旋风改变局部风场，让云朵、纸飞机与天气机关产生互动。

## 玩法目标

- 唤醒三座风车，让盛夏大季风与水彩彩虹重返山谷
- 护送四架纸飞机完成信件投递
- 驱散两处雨云，让两朵向日葵重新盛开
- 完成全部目标后触发额外庆典

## 操作方式

### 桌面端
- **A / D** 或 **← / →**：移动
- **Space / W / ↑**：跳跃；长按可展开伞篷滑翔
- **鼠标左键拖动**：划出风线，推动云朵并护送纸飞机
- **按住鼠标右键**，或按 **E / Shift**：旋风聚云、吹散雨云

### 移动端
- 左侧方向键：移动
- **旋风**：持续聚气
- **跳/滑翔**：跳跃与滑翔

## 实现说明

- 单文件 HTML，使用原生 JavaScript 与 Canvas 2D
- 风场、云朵、纸飞机、粒子与角色运动均在页面内实时计算
- 风声、钟鸣和交互音效通过 Web Audio API 程序化生成
- 不依赖外部图片、模型、音频文件、CDN 或构建工具
- 使用固定步长物理更新，并对粒子与划风线段使用预分配对象池

## 本地运行

直接用现代浏览器打开 `index.html` 即可；建议通过本地 HTTP 服务运行，以获得更一致的浏览器行为。
