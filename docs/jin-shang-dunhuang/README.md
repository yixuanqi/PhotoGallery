# 锦上敦煌 · 纹样穿搭

以敦煌飞天为画布，为衣饰挑选纹样并完成自己的搭配作品。

## 使用方式

1. 选择人物和装饰部位。
2. 选择纹样，可调整纹样大小、旋转角度和颜色。
3. 使用“推荐搭配”、撤销、重做、清空本部位或重新开始。
4. 进入“生成作品”步骤，预览并保存作品。

项目为单页 HTML，页面图形、纹样、样式和交互脚本均内置在 `index.html`，无需安装依赖或启动构建流程。

## 设备适配

支持电脑浏览器，并为手机横屏增加了紧凑工作台布局。手机竖屏保留原有响应式布局。
