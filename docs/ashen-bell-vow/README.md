# 灰钟残誓 (Ashen Bell Vow) — v15.2

## V15.2 发布说明

在 v14 基础上，新增 `i18n.js`、`renderLighting.js`、`storage.js`、`uiNav.js`，并优化移动端光影性能、弹窗裁剪与置顶返回键。

## v14 系统基础

纯程序化水墨手绘、0 外部图片、0 外部音频文件、零构建原生 ES Modules，完整跑通「动态交互式配乐 + 解题型敌兵生态 + 据点锻造循环 + 房间化关卡编辑器造新房」生产流：

- **Web Audio D 弗里吉亚动态交互式配乐（`src/audio.js`）**：
  - 实时 16 分音符程序化编曲器：探索期稀疏青铜编钟与泛音拨弦（72 BPM）→ 遇敌切入低音鼓点与节奏低音（98 BPM）→ Boss 一阶段驱动打击与对位旋律（114 BPM）→ Boss 二阶段高速切分鼓点与连弹高频和声（132 BPM），可在「设置」中独立开关配乐。
- **3 种解题型新敌兵（同步接入 `editor.html` 工具栏）**：
  - **敲钟祭司（`priest`）**：高台咏钟为友军施加「钟佑护盾」（减伤 65%）；钩索对其高优先级锁定，打断咏钟造成 1.5 倍削势，击杀或处决瞬间震碎全场护盾。
  - **连刃武者（`duelist`）**：2-Bone IK 双刃快慢刀武者，高速 3 连斩（快-快-慢闪金芒），连续弹反不会被首刀打断，奖励「叮-叮--叮」连弹打铁破势。
  - **倒挂墨蛭（`leech`）**：悬于穹顶/平台底部滴墨伏击，奖励上挑斩（`W+斩`）与镇魂钟鸣（`W+法`）空中截击（1.45 倍截击伤害）。
- **据点 NPC（盲眼老铸钟匠 · 砺）+ 残响淬炼体系**：
  - 击杀任意敌兵与首领获得「残响」货币，回到起点 `r01_sanctuary` 铁砧旁与老铸钟匠交互，可消耗残响永久强化：**淬炼断刃（Lv.5，+70% 近战伤害）**、**重铸钟势（Lv.3，+36% 削势）**、**魂炉扩焰（Lv.3，+45 生命与魂火）**。
- **第 6 个隐藏回环房间 `r06_crypt.json`（残钟地窖 · 幽窖墨烛新生态色板）**：
  - 藏于沉渊钟井「井中悬坛」西侧墨蚀暗墙之后，集齐全部 3 种新敌兵与 `+220 残响` 秘库宝匣；突破地窖后可经西侧单向暗梯直接攀回 `r02_corridor` 礼拜堂前断索祭坛，形成完整银河恶魔城箱庭闭环！

## 本地一键启动
* **Windows**：直接双击 **`start_game.bat`**（纯 ASCII + CRLF）。
* **macOS / Linux**：运行 **`./start_game.sh`**。
* **游戏入口**：`http://localhost:8080/`（玩家界面保持纯净，不暴露编辑器入口）
* **内部开发用关卡编辑器（仅本地手动访问）**：`http://localhost:8080/editor.html`
