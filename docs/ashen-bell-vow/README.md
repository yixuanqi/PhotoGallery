# 灰钟残誓 (Ashen Bell Vow) — v21.0 风 · 林 · 山三大生态扩展版

纯程序化水墨手绘、**0 外部 PNG 贴图**、0 外部音频文件、零构建原生 ES Modules。在 v20.1 探索/支线解锁三系兵刃（灰钟断刃 / 镇渊钟锤 / 引魂摇铃）与切刃派生技的基础上，将 8 房间箱庭扩展为严丝合缝的 **11 房间全境箱庭**，正式实装 **绝风断塔 (`wind`) · 枯墨古林 (`forest`) · 霜骸圣脊 (`mountain`)** 三大全新生态与专属环境互动机制。

## v21.0 核心更新
- **三大全新生态房间（11 房间 100% 严丝合缝，零破坏既有存档）**：
  1. **绝风断塔 (`r09_wind_spire`, `wind`)**：位于沉渊钟井上层东侧与初钟圣阶西上层之间（打破钟井东上层风蚀暗墙进入）。引入全新 **「罡风上升气流 (`windZones`)」** 机制，乘青白水墨风流飞跃断塔飞扶壁、经幡与钟摆，打通直抵初钟圣阶上层的高空捷径；内置新祭坛「断塔·绝风坛」、残碑「绝风塔铭」与塔巅秘宝「绝风残核」。
  2. **枯墨古林 (`r10_ink_woods`, `forest`)**：位于残钟地窖西侧铸匠秘库深处（穿过 `vb_crypt` 暗蚀结界向西步入）。引入全新 **「荧光弹性孢伞 (`bouncePads`)」** 机制，踩踏弹性发光孢盖高高腾跃并刷新空中二段跳/冲刺；配备全新「三钟共鸣」谜题、祭坛「古林·根窟坛」、残碑「古林根录」，并在最西端暗井破开枯根封壁**直返起点熄灯祭坛**，完成经典魂系箱庭大闭环！
  3. **霜骸圣脊 (`r11_frost_ridge`, `mountain`)**：位于初钟圣阶东下层（破开寒霜暗壁踏入）。满布寒霜冰晶簇、逆风上升寒流与风雪残刃冢，由重盾铁卫、敲钟祭司与连刃武者联合镇守；内置新祭坛「霜脊·残刃坛」、残碑「霜骸剑铭」与终极秘宝「霜骸魂晶」。
- **羊皮纸舆图 & 音景 & 残卷全面升级 (`src/ui.js` / `src/audio.js` / `src/codex.js`)**：
  * 11 房间羊皮纸舆图新增**分生态淡彩底纹**、**上下双层防重叠房间标签**、上升气流与孢伞标记，全境 8 座祭坛支持自由提灯跃迁。
  * 新增 `wind` / `forest` / `mountain` 三套独立跨房交叉音景；《晦渊残卷》收录扩展至 **8 座残碑 / 16 项成就**（新增成就「三境踏破」），中英双语 100% 同步。

## 本地一键启动 / Local Launch
* **Windows**：直接双击 **`start_game.bat`**（或运行 `python serve_local.py`）。
* **macOS / Linux**：运行 **`./start_game.sh`**。
* **游戏入口**：`http://localhost:8080/`
* **关卡编辑器**：`http://localhost:8080/editor.html`
