## 本地一键启动
* **Windows**：直接双击 **`start_game.bat`**（纯 ASCII + CRLF）。
* **macOS / Linux**：运行 **`./start_game.sh`**。
* **游戏入口**：`http://localhost:8080/`
* **内部关卡编辑器**：`http://localhost:8080/editor.html`
