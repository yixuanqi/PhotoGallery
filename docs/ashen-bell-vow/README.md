# 灰钟残誓 (Ashen Bell Vow) — v19.0 纯程序化水墨画质升级版

纯程序化水墨手绘、**0 外部 PNG 贴图**、0 外部音频文件、零构建原生 ES Modules。在完整保留 v18.3 全部中英双语、8 房间箱庭、3 位多阶段首领、双圣物槽羁绊、三位 NPC 支线与真二周目（NG+）的基础上，全面重构了底层场景渲染管线：

## v19.0 核心更新
- **纯程序化水墨图章库 (`src/stampAtlas.js`)**：内置 13 种高精细度离屏缓存水墨图章（残破石拱、半埋断钟骸、守誓者残像、垂吊古铁链、巨型旋转铜齿轮、悬吊熔坩埚、荧光孢菌簇、风雪残刃冢、断塔飞扶壁、罡风破经幡、分形枯古木、墨染垂枝冠、寒霜冰晶簇），支持 `bg`/`fg` 前后景分层与动态风动/旋转动画。
- **1024×800 分块离屏有机地形缓存 (`src/renderTerrain.js`)**：以确定性世界噪点取代硬直矩形块，为地面、悬崖、石柱与浮台离线烘焙自然岩石凹凸、对角水墨排线、深岩裂纹与 11 套生态自动覆层（青苔、绯金浮雕、潮雾矿晶、锻铁熔纹、风蚀斜切、厚雪冰棱），运行时每帧仅 2–4 次 `drawImage` 贴图，144Hz 更稳更省 CPU。
- **分生态 3 层离屏视差背景 (`src/renderParallax.js`)**：为回廊、圣殿、钟井/地窖、古炉/圣阶及未来风/林/山四大板块提供专属远中近视差瓦片，跨房平滑交叉淡入淡出。
- **关卡编辑器图章工具 (`editor.html` / `src/editor.js`)**：支持可视化点选 13 种水墨图章、实时所见即所得预览，以及层级、缩放、水平翻转、变体种子与透明度调节。
- **全境 8 房间精装翻新**：已为 `r01`–`r08` 布置 66 处手工构图的水墨场景图章，保持战斗主通道清晰且极具层次感。

## 本地一键启动 / Local Launch
* **Windows**：直接双击 **`start_game.bat`**。
* **macOS / Linux**：运行 **`./start_game.sh`**。
* **游戏入口**：`http://localhost:8080/`
* **关卡编辑器**：`http://localhost:8080/editor.html`
