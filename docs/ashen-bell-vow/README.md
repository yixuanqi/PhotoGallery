# 灰钟残誓 (Ashen Bell Vow) — v12-A 零贴图视听质变版

沿用纯程序化水墨手绘与零构建原生 ES Modules 路线（无外部 PNG 大图），在 v11 房间化架构上完成 **迭代 2（v12-A）** 视觉与动态表现升级：

- **2D 提灯实时硬阴影与体积光束（`src/renderer.js`）**：基于 `SOLIDS` 建筑几何、暗墙与闸门做实时射线投影，主角腰间魂火提灯（居合/反击蓄满时切金芒）与最近的摇曳悬灯共同在石柱、平台后投出随角色移动而旋转拉长的**墨色硬阴影**，并切割出实时**体积光束**（半分辨率双离屏画布，高性能低开销）。
- **房间生态主题四色水墨色板与程序化天气（`src/config.js` / `src/world.js` / `src/renderer.js`）**：读取房间 JSON 中的 `theme` 字段平滑过渡天空、雾气与点缀色板，并切换专属程序化天气——
  - `sanctuary`（熄灯冷境）：幽蓝冷灰与慢飘魂灰
  - `corridor`（墨雨长廊）：阴沉斜落墨雨，雨滴与脚步踩踏会在地面水洼激起同心涟漪
  - `chapel`（绯灰圣殿）：飘落骨灰雪（Boss 二阶段转猩红余烬）
  - `bell_well`（碧渊潮雾）：深邃碧青潮雾升腾与洞壁水滴坠落暗河激起波纹
  - `foundry`（熔金古炉）：炙热升腾熔炉火星
  - 关卡编辑器 `editor.html` 的「房间属性」中现已支持下拉切换 `生态主题`。
- **轻量 2-Bone IK 逆向运动学腿脚与动态姿态（`src/vfx.js` / `src/player.js` / `src/renderer.js`）**：
  - 主角双脚采用两段式 IK 驱动并**自动贴合地面/台阶边缘高度**；新增落地瞬间膝盖下蹲缓冲（`landCrouch`）、疾跑/闪避/蓄力/弹反躯干动态前倾与急停甩披风动量（`bodyLean`）。
  - **断钟骑士 · 晦**升级重甲 IK 腿部，架势崩毁进入处决状态时单膝重跪于地；**持矛枯骨哨兵**亦同步升级 IK 步态。

## 本地一键启动与编辑

* **Windows**：直接双击 **`start_game.bat`**（纯 ASCII + CRLF，彻底兼容中文 Windows cmd）。
* **macOS / Linux**：运行 **`./start_game.sh`**。
* **游戏地址**：`http://localhost:8080/`
* **关卡编辑器**：`http://localhost:8080/editor.html`（或点击游戏右上角「关卡编辑」）
