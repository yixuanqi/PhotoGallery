战斗心法
三段弹反 · 居合一闪 · 幽鸣灵刃 · 幽丝钩索 · 墨印处决
1. 立体断刃剑技 [J]：轻按三连（上挑 → 横扫 → 踏步重劈）；长按 [J] 沉身收刀蓄力，金芒闪现后松开释放贯穿「居合 · 一闪」；配合 [W+J] 上挑斩、空中 [S+J] 踩头与悬灯下劈弹跳。
2. 幽鸣灵刃 [U] & 幽丝钩索 [I / F / 右键]：挥刀与弹反回复魂火，按 [U] 耗 30 魂火发射穿透灵刃（命中悬灯可触发「灯鸣震荡」范围爆发）；对准带准星的悬灯、铜钩环或敌人按 [I / F / 右键] 高速钩跃，钩中悬灯可翻跃并刷新闪避！
3. 精准弹反 [K] & 识破反击 [K → J]：0–140ms 完美弹反零伤打铁（可反弹怨灵火球！）并攒墨印；弹反后 0.5 秒内按 [J] 派生「断钟返 · 十字反击斩」，双倍吸血狂削架势。
4. 普通格挡与红光「危」：140–260ms 普通格挡化为内伤灰血，平 A 可吸回实血；猩红「危」技不可弹反，需按 [Shift] 闪避或钩索飞跃。
5. 墨印引爆 [L] 与处决 [J]：攒墨印后按 [L] 突刺贴符引爆；敌方架势崩溃跪地时，近身按 [J] 触发黑白反色处决！
