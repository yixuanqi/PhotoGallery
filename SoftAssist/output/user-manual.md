## 一、软件概述

### 1.1 软件简介

小笨相册（Photo Gallery）是一款具有独特手绘风格的照片浏览应用。软件以"晾衣绳"的形式展示您的照片，每张照片都像一张拍立得照片，用木质夹子挂在绳子上，营造出温馨怀旧的氛围。

### 1.2 主要特点

- **独特的手绘风格界面**：采用吉卜力风格的背景渲染，山丘、草地、阳光构成宁静的画面
- **创意的照片展示方式**：照片以拍立得形式悬挂在晾衣绳上，自然垂落
- **智能的时间分组**：自动按月份对照片进行分组，方便快速定位
- **流畅的手势操作**：支持滑动浏览、双指缩放、双击查看详情
- **隐私保护**：支持Android 14的部分照片访问权限，只访问您选择的照片

### 1.3 适用人群

- 喜欢独特视觉体验的用户
- 追求个性化照片浏览方式的用户
- 注重隐私保护的用户

## 五、操作指南

### 5.1 授予照片权限

**操作步骤**：

1. 首次启动应用时，会弹出权限请求对话框
2. 点击"选择照片权限"按钮
3. 在系统权限设置页面中：
   - **Android 14及以上**：可选择"允许访问所有照片"或"选择照片"
   - **Android 13及以下**：点击"允许"即可
4. 返回应用，照片将自动加载

**注意事项**：
- 如果选择"选择照片"，应用只能访问您选中的照片
- 可以随时在系统设置中修改权限

### 5.2 浏览照片

**基本操作**：

| 操作 | 方法 |
|-----|------|
| 滑动浏览 | 左右滑动屏幕 |
| 查看当前时间 | 查看顶部时间指示器 |
| 打开时间选择器 | 点击顶部时间指示器 |

**滑动浏览说明**：
- 向左滑动：查看较新的照片
- 向右滑动：查看较早的照片
- 滑动有惯性效果，轻滑即可快速浏览

### 5.3 使用时间导航

**打开时间选择器**：

1. 点击顶部的月份指示器（如"2025年3月"）
2. 弹出时间选择面板
3. 选择想要跳转的月份
4. 自动定位到该月份的照片

**时间分组说明**：
- 照片按拍摄时间自动分组
- 没有时间信息的照片归入"未知时间"组
- 每组显示照片数量

### 5.4 查看照片详情

**进入详情模式**：

方法一：双击照片
方法二：点击时间指示器旁的"查看"按钮

**详情界面操作**：

| 操作 | 方法 |
|-----|------|
| 放大照片 | 双指捏合放大 |
| 缩小照片 | 双指捏合缩小 |

**手势说明**：
- 双指缩放：用两个手指同时触摸屏幕，向外拉开放大，向内捏合缩小
- 滑动切换：单指左右滑动切换照片
- 放大状态下可以拖动查看照片细节

### 5.5 管理照片权限（Android 14+）

**修改权限设置**：

1. 打开系统"设置"
2. 进入"应用管理"
3. 找到"小笨相册"
4. 点击"权限"
5. 选择"照片和视频"
6. 修改权限设置：
   - "允许"：可访问所有照片
   - "不允许"：无法访问照片
   - "选择照片"：只能访问选中的照片

## 六、常见问题

### Q1：应用无法显示照片？

**可能原因**：
1. 未授予照片访问权限
2. 相册中没有照片
3. 权限被系统限制

**解决方法**：
1. 检查并授予照片权限
2. 确认相册中有照片
3. 在系统设置中重新配置权限

### Q2：照片加载很慢？

**可能原因**：
1. 照片数量过多
2. 照片分辨率过高
3. 设备性能较低

**解决方法**：
1. 等待加载完成
2. 关闭其他后台应用
3. 使用时间导航跳转

### Q3：如何只让应用访问部分照片？

**解决方法**（Android 14+）：
1. 在权限设置中选择"选择照片"
2. 勾选想要分享的照片
3. 返回应用即可

### Q4：详情界面照片模糊？

**可能原因**：
1. 照片本身分辨率较低
2. 缩放比例过高

**解决方法**：
1. 查看原图分辨率
2. 适当缩小查看

### Q5：应用闪退或卡顿？

**可能原因**：
1. 内存不足
2. 系统版本不兼容

**解决方法**：
1. 清理后台应用
2. 重启应用
3. 检查系统版本是否满足要求
